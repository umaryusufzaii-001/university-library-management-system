# System Diagrams

## Introduction
This folder contains the system diagrams of the University Library Management System (LMS).

## Purpose
These diagrams represent the structure, functionality, and workflow of the proposed library management system.

## Diagrams Included

1. **Use Case Diagram:** Shows the interaction between students, librarians, and the library management system.

2. **Class Diagram:** Represents the main classes, attributes, and relationships in the system.

3. **Activity Diagram:** Shows the workflow of book borrowing, returning, and reservation.

- Microsoft Visio
