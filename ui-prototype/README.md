# UI Prototype

## Introduction
This folder contains the user interface prototype of the University Library Management System.

## Purpose
The purpose of this prototype is to demonstrate how students and librarians will interact with the proposed system.

## Proposed Interface Screens

1. Login Page
2. Student Dashboard
3. Book Management Page
4. Book Borrowing Page
5. Book Return Page
6. Book Reservation Page
7. Overdue Notification Page
