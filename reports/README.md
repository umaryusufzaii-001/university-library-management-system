# Project Reports

## Introduction
This folder contains the project planning and management reports for the University Library Management System.

## Reports Included

1. Project Schedule
2. Gantt Chart
3. Work Breakdown Structure (WBS)
4. Responsibility Assignment Matrix (RAM)
5. Project Risk Analysis
6. Effort Estimation

## Purpose
These reports help the software engineering team organize project activities, assign responsibilities, manage time, and identify possible risks.

University Library Management System
