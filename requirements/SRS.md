# Software Requirements Specification (SRS)

## 1. Introduction
The University Library Management System is designed to automate university library operations and replace manual record keeping.

## 2. Functional Requirements

- FR-01: The system shall allow librarians to add, update, and delete book records.
- FR-02: The system shall allow student registration and membership management.
- FR-03: The system shall record book borrowing.
- FR-04: The system shall manage book returns.
- FR-05: The system shall allow students to reserve books.
- FR-06: The system shall track overdue books.
- FR-07: The system shall send overdue notifications.

## 3. Non-Functional Requirements

- The system should be user-friendly.
- The system should protect user information.
- The system should provide reliable records.
- The system should respond efficiently.
- The system should be available during library operating hours.

## 4. Users

1. Administrator
2. Librarian
3. Student

## 5. Project Scope
The project covers book management, membership, borrowing, returns, reservations, and overdue notifications.

## 6. Project Limitations
The complete software implementation is not included in this academic project.
